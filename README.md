# Fruits By Pili — Landing Page

Landing page estática para Fruits By Pili (ensaladas de frutas colombianas), optimizada para SEO y desplegada en Vercel.

## Contenido
- `index.html` — página única con hero, catálogo, sobre nosotros y contacto.
- `styles.css` — estilos.
- `script.js` — pequeño script (año dinámico del footer).
- `robots.txt` / `sitemap.xml` — SEO técnico.
- `vercel.json` — configuración de despliegue.
